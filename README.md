# sezx — Claude Code + Google Gemini

Связка, в которой Claude Code может сам обращаться к Google Gemini: за вторым мнением,
ревью кода, анализом больших файлов и т. п.

## Что внутри

| Файл | Назначение |
|---|---|
| `gemini-mcp/server.mjs` | MCP-сервер (без зависимостей, нужен только Node.js 18+) |
| `.mcp.json` | Подключает сервер к Claude Code автоматически при открытии проекта |
| `gemini-mcp/ask.mjs` | Быстрый вызов Gemini из терминала |
| `CLAUDE.md` | Подсказывает Claude, когда стоит звать Gemini |

Инструменты, которые получает Claude:

- **`ask_gemini`** — задать Gemini любой вопрос;
- **`gemini_review_files`** — отправить файлы проекта в Gemini с заданием (ревью, поиск ошибок);
- **`gemini_list_models`** — список доступных моделей.

## Шаг 1. Получить ключ Gemini API

1. Откройте <https://aistudio.google.com/apikey>.
2. Нажмите **Create API key** и скопируйте ключ.

## Шаг 2. Добавить ключ

### В облаке (claude.ai/code)
Для этого репозитория уже создано облачное окружение **`sezx`**.
Откройте настройки окружения → **Network secrets** → добавьте секрет:

- Host: `generativelanguage.googleapis.com`
- Header: `x-goog-api-key`
- Value: ваш ключ

Можно просто написать Claude в сессии «запроси ключ Gemini» — откроется защищённая форма.
**Не вставляйте ключ в чат.**

### Локально (или в текущем контейнере)
Создайте файл `.env` в корне проекта (он в `.gitignore`):
```
GEMINI_API_KEY=ваш_ключ
```
или задайте переменную:
```bash
export GEMINI_API_KEY="ваш_ключ"
```

## Шаг 3. Пользоваться

Откройте проект в Claude Code (при первом запуске подтвердите MCP-сервер `gemini`) и пишите, например:

- «Спроси у Gemini, как лучше спроектировать эту БД»
- «Пусть Gemini сделает ревью `src/app.js`, потом сравни со своим мнением»
- «Напиши функцию, а Gemini пусть её проверит»

Из терминала:
```bash
node gemini-mcp/ask.mjs "Объясни разницу между TCP и UDP"
cat src/app.js | node gemini-mcp/ask.mjs "Найди ошибки в этом коде"
```

## Настройки

| Переменная | По умолчанию | Описание |
|---|---|---|
| `GEMINI_API_KEY` | — | Ключ (не нужен, если он сохранён как секрет облачного окружения) |
| `GEMINI_MODEL` | `gemini-3.5-flash` | Основная модель |
| `GEMINI_FALLBACK_MODELS` | `gemini-3.5-flash-lite` | Запасные модели через запятую (если основная перегружена или молчит) |
| `GEMINI_TIMEOUT_MS` | `45000` | Сколько ждать ответа от одной модели |
